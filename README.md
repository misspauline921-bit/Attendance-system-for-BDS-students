## Student Attendance System.
##  Overview
This system is used to record the daily attendance for a class of 50 students. The system also allows the lecturer to mark attendance.
It is an array application system.
## Objectives
- Recording the number of students present and those who are absent.
-  Allowing the lecturer to mark the attendance.
-  Listing the students who are absent.
